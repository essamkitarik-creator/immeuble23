# تطبيق العمارة 23 — المجمع العقاري البيضاء (إقامة البيضاء سيدي مومن)

تطبيق ويب ثابت (HTML + JavaScript) يتصل بقاعدة بيانات Supabase.

## الملفات
- index.html : الصفحة الرئيسية والتنسيق وتحميل باقي الملفات
- core.js : الاتصال بقاعدة البيانات، تسجيل الدخول، الحسابات الأساسية، التنقل
- v-sum.js (الملخص والرسوم) · v-pay.js (الدفعات وتسديد الأشهر والديون) · v-own.js (الملاك)
- v-set.js (Paramétrer: حسابات الدخول والرموز) · v-misc.js (المصاريف والإصلاحات)
- vote.js (التصويت على الإصلاح) · tre.js (الخزينة وتدقيق الحسابات)
- rcp.js (الإيصالات) · legal.js (الإشعار القانوني) · ann.js (الإعلانات) · dl.js (التحميل CSV)
- pdf.js (كل الطباعات بصيغة PDF)
- manifest.json · sw.js · icon-192.png · icon-512.png : تثبيت التطبيق بملء الشاشة

## التشغيل
1. ارفع كل الملفات كما هي إلى أي استضافة ملفات ثابتة (Vercel، Netlify، GitHub Pages ...).
2. افتح الرابط. الاتصال بقاعدة Supabase مضبوط داخل core.js (المتغير SB).
3. لاستعمال قاعدة بيانات أخرى غيّر عنوان المشروع والمفتاح العام (publishable key) في core.js.

## ملاحظات
- الأمان الفعلي (من يرى ماذا) مضبوط في قاعدة Supabase عبر سياسات RLS، وليس في هذه الملفات.
- المفتاح الموجود في core.js هو مفتاح عام مخصص للمتصفح.
- الاتصال بالإنترنت لازم لتحميل مكتبات Chart.js و Supabase و html2pdf من CDN.
